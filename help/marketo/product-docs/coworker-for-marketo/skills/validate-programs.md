# 验证程序 {#validate-programs}

审核您的项目以获得所有组件（如电子邮件、登陆页面、营销活动等）的最佳实践。

## 使用方法 {#how-to-use}

1. 在“我的Marketo”中，单击&#x200B;**Marketo Engage同事**&#x200B;图块。

   ![](assets/validate-programs-1.png)

1. 在提示窗口中键入“I want to validate a Marketo Engage program”。

   ![](assets/validate-programs-2.png)

1. 在右窗格中选择要验证的程序。

   ![](assets/validate-programs-3.png){width="800" zoomable="yes"}

   所选程序的摘要将显示在中心窗格中。

1. 在提示窗口中，输入“验证程序”并单击&#x200B;**发送**。

   Co-worker for Marketo Engage提供选定项目的QA，向您显示哪些项目通过以及哪些项目失败。

   ![](assets/validate-programs-6.png)
