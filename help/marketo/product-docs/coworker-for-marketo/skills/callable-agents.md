# 可调用代理 {#callable-agents}

可调用代理允许您将AI代理用作Marketo Engage Smart Campaign中的步骤。 在CX Enterprise Coworker for Marketo Engage中构建代理，选择它读取和更新的潜在客户字段，然后发布它以用于营销活动。 代理可帮助清理数据、对潜在客户进行分类、丰富缺失信息或筛选表单提交。

>[!PREREQUISITES]
>
>您必须在Marketo Engage中具有&#x200B;**访问管理员**&#x200B;权限。

## 开始之前 {#before-you-begin}

- 确定代理需要读取哪些潜在客户字段以及它应更新哪些字段。 每个输入和输出都必须映射到Marketo Engage商机字段。
- 确认输出字段可更新。 不支持只读字段和项目群成员字段。

## 使用方法 {#how-to-use}

1. 在“我的Marketo”中，单击&#x200B;**[!UICONTROL CX Enterprise Coworker for Marketo Engage]**&#x200B;磁贴。

1. 在左侧导航中选择&#x200B;**[!UICONTROL Callable agents]**。 该列表显示每个座席的名称、创建日期、创建者和状态。 按名称搜索或按名称或创建日期排序。

1. 选择 **[!UICONTROL Create callable agent]**。 选择一个模板，或将模板选择器保留为空将从头开始。

1. 输入&#x200B;**[!UICONTROL Agent name]**&#x200B;并写入&#x200B;**[!UICONTROL Agent instructions]**，说明如何处理每个潜在客户。

1. 在&#x200B;**[!UICONTROL Lead fields to send]**&#x200B;下，添加代理所需的潜在客户字段作为输入。 在&#x200B;**[!UICONTROL Lead fields to update]**&#x200B;下，添加代理应返回的每个值，并将其映射到可更新的潜在客户字段。

1. 选择&#x200B;**[!UICONTROL Save]**&#x200B;以保存草稿，或选择&#x200B;**[!UICONTROL Save and publish]**&#x200B;以使代理在Marketo Engage中可用。

1. 打开Smart Campaign并选择&#x200B;**[!UICONTROL Flow]**&#x200B;选项卡。 在流程步骤列表的“营销”部分中，找到&#x200B;**呼叫代理： _[代理名称]_**，并将其拖动到流程中。

1. 使用一小部分潜在客户测试营销活动。 查看活动日志，确认输出字段会按预期更新，然后再为所有潜在客户激活营销活动。

## 注意事项 {#things-to-note}

- 可调用代理独立处理每个潜在客户。 Marketo Engage将映射的潜在客户值发送到代理，将返回的值写入映射的潜在客户字段，然后继续下一个营销活动步骤。
- 您可以在CX Enterprise Coworker中为Marketo Engage创建和管理可调用代理。 无需外部连接。
- 已发布的代理不可编辑。 要更改已发布的代理，您必须创建新代理并更新相关的智能营销活动。

## 创建代理 {#create-an-agent}

### 从头开始创建代理 {#create-an-agent-from-scratch}

将模板选取器留空。 表单以一个空输入字段和一个空输出字段开头。 输入名称和说明，然后配置输入和输出字段以匹配业务规则。

### 从模板开始 {#start-from-a-template}

选择模板以预填说明、输入字段和输出字段。 代理将另存为自己的副本，您可以对其进行编辑或删除。 如果删除从模板创建的代理，则该模板将再次在选取器中可用。

| 模板 | 用途 | 输入 | 输出 |
| --- | --- | --- | --- |
| 公司名称标准化器 | 通过删除法律后缀、更正常见的拼写错误并应用标准品牌大小写来清理公司名称。 | 公司 | 规范化的公司（文本）；置信度（数字） |
| 电话E.164格式化程序 | 按照国际E.164标准格式化电话号码。 | 电话 | 规范化的电话（文本）；置信度（数字） |
| 职位标准器 | 将职称标准化，并取得资历。 | 标题 | 规范化的标题（文本）；资历（高级别、副总裁、主管、经理、个人或未知）；置信度 |
| 机器人和垃圾邮件检测器 | 标记机器人或垃圾邮件表单提交。 | 电子邮件、名字、姓氏、公司、电话 | 为机器人(true/false)；置信度；原因；标志（逗号分隔） |
| 一次性电子邮件检测器 | 标识临时或可处置的电子邮件地址。 | 电子邮件 | 是机器人(true/false)；置信度；原因；电子邮件类型（一次性、个人或企业） |
| 潜在客户分类器 | 按公司规模、行业、角色和意图划分的区段潜在客户。 | 公司、职位、电子邮件、员工、收入 | 区段（企业、中端市场、SMB、初创公司或未知）；行业；角色；意图级别（高、Medium或低）；置信度 |
| 商机扩充 | 推断缺少可用信息中的潜在客户详细信息。 | 电子邮件、职位、公司 | 推断的公司、部门、资历、是决策者（真/假）、是B2B（真/假）、置信度 |
| 公司研究 | 从公司信息生成销售情报。 | 公司、网站、描述 | 有关完整列表，请参阅模板 |

### 编写有效的指令 {#write-effective-instructions}

- 在代理说明中放入一般规则和示例。 使用字段说明指定单个输出的期望值。
- 具体点。 例如，“删除Inc、LLC和Corp等法律后缀”比“清理公司名称”更清晰。
- 包括输入和预期输出的示例，尤其是对于边缘情况。
- 说明代理在无法做出决定时应返回的内容，例如“如果您不确定，则返回原始值”。
- 添加置信度输出，以便营销活动逻辑可以路由低置信度结果以供审查。
- 保持提示简洁。 较短的提示运行速度更快，成本更低。

## 保存、发布和管理代理 {#save-publish-and-manage-agents}

### 另存为草稿或发布 {#save-as-a-draft-or-publish}

选择&#x200B;**[!UICONTROL Save]**&#x200B;将代理另存为草稿。 草稿可以编辑，但不能作为Smart Campaign流量步骤使用。 在代理准备就绪后，选择&#x200B;**[!UICONTROL Save and publish]**。 Marketo Engage将代理作为流程步骤提供，并在确认发布后返回到代理列表。 选择要离开而不保存的&#x200B;**[!UICONTROL Cancel]**。

| 状态 | 含义 | 可用操作 |
| --- | --- | --- |
| 草稿 | 代理已保存，但在Marketo Engage中不可用。 | 编辑它，然后在准备就绪时选择&#x200B;**[!UICONTROL Save and publish]**。 |
| 发布日期 | 代理在Smart Campaigns中可用。 已发布的代理已冻结。 | 使用已发布的代理，或创建新代理以进行更改。 |
| 发布失败 | 例如，Marketo Engage拒绝了代理，因为保留了输出字段名称。 但代理仍会保存为草稿。 | 编辑代理，更正消息中命名的字段，然后重新发布。 |

### 编辑、检查使用情况或删除 {#edit-check-usage-or-delete}

- 选择草稿上的&#x200B;**[!UICONTROL Edit]**&#x200B;以更改草稿。 **[!UICONTROL Save]**&#x200B;让您在页面上停留并显示“代理已保存”确认。 您还可以选择&#x200B;**[!UICONTROL Save and publish]**、**[!UICONTROL Cancel]**&#x200B;或&#x200B;**[!UICONTROL Delete]**。
- 已发布的代理会被冻结，因为Smart Campaigns可能依赖于它们。 创建新代理以进行更改。
- 在删除代理或更改其活动设置之前，请查看&#x200B;**[!UICONTROL Used by]**&#x200B;以查看哪些智能营销活动引用代理。
- 当Smart Campaign仍在使用代理时，您无法删除该代理。 从每个列出的活动中删除代理的流程步骤，然后删除代理。

## 组织规则集成 {#organizational-rules-integration}

### 命名约定 {#naming-conventions}

- **代理名称：** 1-100个字符，在订阅中是唯一的。 该名称还在Smart Campaign流程步骤中使用。 选择可识别的名称，如`Company Name Normalizer`。
- **输出字段名称：**&#x200B;使用字母、数字和下划线。 名称必须以字母或下划线开头，必须唯一且不超过64个字符。
- **保留名称：**&#x200B;某些输出名称保留供系统使用。 如果名称被拒绝，请选择其他名称，如`qualificationReason`而不是`reason`。

### 必需元素和支持的字段 {#required-elements-and-supported-fields}

- 在保存之前，将每个输入字段映射到Marketo Engage潜在客户字段。
- 配置至少一个输出字段。 将每个输出映射到可更新的潜在客户字段；字段选取器中没有只读字段。
- 不支持项目群成员字段。 字段选取器仅显示潜在客户字段。
- 支持的输出类型为&#x200B;**Text**、**Number**&#x200B;和&#x200B;**True/False**。
- 要返回列表，请使用逗号分隔的文本值，并在字段说明中描述预期格式。
- 每次成功运行都将返回完全配置的输出字段。

### 限制 {#limits}

| 设置 | 限制 |
| --- | --- |
| 代理名称 | 1-100个字符；在订阅中唯一 |
| 代理说明 | 1 - 4,000个字符 |
| 输入字段 | 最多20个；每个都必须映射到潜在客户字段 |
| 输出字段 | 1-20；每个字段都必须映射到可更新的潜在客户字段 |
| 输出字段名称 | 最多64个字符；字母、数字和下划线；以字母或下划线开头；唯一 |
| 输出字段说明 | 最多512个字符 |
| 每个请求的潜在客户 | 来自Marketo Engage的多达1,000个并行处理的潜在客户 |

## 内容筛选和数据处理 {#content-screening-and-data-handling}

在创建代理或编辑代理说明时，Marketo Engage会筛选代理说明，并输出违反策略、提示注入和数据导出尝试的字段说明。 示例包括显示凭据或覆盖代理行为的请求。 如果内容被标记，则保存会被阻止，并且可能会显示一条消息，如“提示包含受限内容”或“提示失败的内容审核”。 修订文本并再次保存。

- **访问：**&#x200B;管理代理需要&#x200B;**访问管理员**&#x200B;权限。 代理和呼叫历史记录由订阅隔离。
- **潜在客户数据保护：**&#x200B;与代理指令分开传递潜在客户数据，并使用将潜在客户值视为数据而非命令的防护措施。
- **内容策略：**&#x200B;如果潜在客户的数据违反AI提供商的内容策略，则该潜在客户将收到错误活动而不是结果。
- **保留：**&#x200B;请求和响应负载（包括发送给代理的潜在客户字段值）在通话历史记录中保留30天以支持故障排除，然后自动删除。

## 可调用代理在营销活动中的运行方式 {#how-callable-agents-run-in-a-campaign}

1. 在营销活动运行时，Marketo Engage会将每个符合条件的潜在客户的映射潜在客户字段值发送给代理。
1. 代理独立处理每个潜在客户并返回配置的输出字段。
1. Marketo Engage将结果写入映射的潜在客户字段。 更改的字段还会显示为标准数据值更改活动。
1. 活动将进入下一步。

处理是异步的。 流步骤将等待结果到Marketo Engage中的流步骤等待窗口。 如果一个商机失败（例如，由于超时），则该商机将收到错误活动，而其他商机将继续。 每个结果都显示在潜在客户的活动日志中，供可调用座席使用。

在营销活动逻辑中使用输出字段。 例如，**上的分支是机器人**，用于以不同的方式路由垃圾邮件提交，或是&#x200B;**置信度**&#x200B;上的分支，用于将低置信度结果发送到审阅步骤。

## 预激活QA {#pre-activation-qa}

在为所有潜在客户激活营销活动之前：

- 使用一小部分测试潜在客户集运行营销活动。
- 查看每个商机的活动日志，并确认输出字段已正确更新。
- 测试边缘情况，包括缺少值和异常输入。
- 确认营销活动分支可按预期处理低置信度或机器人/垃圾邮件分类等值。

## 用例 {#use-cases}

- **数据清理：**&#x200B;在创建或导入潜在客户时，标准化公司名称、将电话号码格式化为E.164，并标准化职称。
- **机器人和垃圾邮件筛选：**&#x200B;检查提交的垃圾邮件名称、可疑电子邮件和重复数字的电话号码；根据结果分支营销活动。
- **一次性电子邮件检测：**&#x200B;识别临时电子邮件地址，并将其路由方式与业务地址不同。
- **潜在客户分类：**&#x200B;按公司规模、行业、角色和支持路由或评分的意图细分潜在客户。
- **潜在客户扩充：**&#x200B;推断缺少的详细信息，如部门、资历，或潜在客户是否为决策者。
- **自定义规则：**&#x200B;生成可描述为潜在客户处理规则的是/否检查或分类，例如标记来自区域或行业的潜在客户。

## 故障排除 {#troubleshooting}

| 问题 | 解决方法 |
| --- | --- |
| **代理**&#x200B;未出现在导航中。 | 请求您的Marketo Engage管理员授予&#x200B;**访问管理员**&#x200B;权限。 |
| 保存操作被内容消息阻止。 | 修订代理说明或字段说明以删除标记的内容，然后再次保存。 |
| 代理状态为&#x200B;**发布失败**。 | 编辑代理，更正消息中命名的字段，然后选择&#x200B;**保存并发布**。 |
| 您无法编辑已发布的代理。 | 已发布的代理已冻结。 创建新代理以进行更改。 |
| 您无法删除代理。 | 使用代理从列出的每个Smart Campaign中删除其流步骤，然后删除它。 |
| 字段名称报告为保留。 | 请选择其他输出字段名称，如`qualificationReason`，然后重新保存。 |
| 某些潜在客户会收到错误活动。 | 检查商机的活动日志。 单个故障（包括超时或内容策略违规）不会影响其他潜在客户。 |
| 意外结果。 | 使说明更加具体，添加示例，优化字段说明，然后使用一小部分潜在客户再次测试。 |

## 后续步骤 {#next-steps}

- 查看代理的&#x200B;**使用者**&#x200B;列表，并确认哪些智能营销活动将使用它。
- 使用一小部分潜在客户测试流程步骤，并验证活动日志和输出字段。
- 使用输出字段为分类或低置信度结果添加促销活动分支。
- 在删除代理之前，请从所有营销活动中删除代理流程步骤。
