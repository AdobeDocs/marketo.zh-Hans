# 编辑移动推送通知 {#edit-mobile-push-notification}

1. 进入 **[!UICONTROL Marketing Activities]** 区域。

![](assets/image2015-4-22-18-3a44-3a42.png)

1. 选择您的移动应用，然后单击&#x200B;**[!UICONTROL Edit Draft]**。

   ![](assets/image2015-4-22-18-3a45-3a13.png)

>[!MORELIKETHIS]
>
